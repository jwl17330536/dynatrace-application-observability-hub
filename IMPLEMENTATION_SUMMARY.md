## Why Adapter Pattern Matters Here

**Before (Tag Query):**
```dql
fetch dt.entity.host
| filter tags["app.tag"] != null
| fields appTag = tags["app.tag"], appName = tags["app.name"], ...
```

**After (Lookup Query):**
```dql
fetch data from table "cmdb_businessapp"
| fields appTag = this["cmdb_ci_key"], appName = this["name"], ...
```

**Same Output Schema:**
```json
{
  "appTag": "APP-001",
  "appName": "Jira Cloud",
  "tier": "Critical",
  "owner": "Platform Team"
}
```

**Result:** Overview.tsx renders identically. This is how Phase 2 can add different visualizations without changing the existing table component.
